# 🎮 Anedolia

> A narrative web game about rediscovering color in life through memories.

## 📖 About

**Anedolia** is a first-person narrative experience where players explore a grayscale apartment, interacting with everyday objects that trigger memories. As the story progresses, color gradually returns to the world — from muted grays to soft pastels to vibrant tones — culminating in a hopeful, emotional ending.

The game explores themes of emotional numbness and recovery, inspired by games like **LIMBO**, **INSIDE**, and **Journey**. All narrative content — internal thoughts, flashback dialogue, memory descriptions, and the final message — is dynamically generated by **Google's Gemini API**, making each playthrough feel unique.

Built for the **Google Gemini API Developer Competition**.

## 📦 Installation

### Prerequisites

- Node.js 18+
- npm or yarn
- Google AI Studio API Key ([Get it here](https://aistudio.google.com/app/apikey))

### Setup

1. **Clone the repository**

```bash
git clone https://github.com/Sofia-gith/Anedolia
cd anedolia
```

2. **Install dependencies**

```bash
npm install
```

3. **Configure environment variables**

Create a `.env.local` file in the root directory (see `.example.env`):

```env
GOOGLE_API_KEY=your_api_key_here
```

4. **Run the development server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎮 Game Design

### Core Concept

Players wake up in a grayscale world and must explore their apartment, interacting with objects that trigger memories. Each memory restores more color to the world.

### Three Acts

1. **Act 1: Awakening (Bedroom)**
   - World is entirely grayscale
   - Interactive objects introduce the story
   - Introduction to controls

2. **Act 2: Memories (Living Room)**
   - Color begins to return
   - Flashback sequences triggered by objects
   - Gemini-generated dialogue and thoughts

3. **Act 3: Revelation (Bathroom)**
   - Mirror interaction
   - Full color restoration
   - Emotional conclusion

### Controls

- **WASD** — Movement
- **Mouse** — Look around
- **E** — Interact with objects

## 🤖 Gemini Integration

The game uses Google's Gemini API to dynamically generate:

- Character's internal thoughts when interacting with objects
- Flashback dialogue and memory descriptions
- The final emotional message

API calls are handled server-side through the `/api/gemini-route` endpoint.
